# addaccessibility
# Name: Add Accessibility
# Description: Add full accessibility support

# Prompt:
Add accessibility to this view:
- .accessibilityLabel() for all interactive elements
- .accessibilityHint() for non-obvious actions
- .accessibilityValue() for current state
- Dynamic Type support
- VoiceOver testing patterns
- Keyboard navigation support

This command will be available in chat with /addaccessibility
