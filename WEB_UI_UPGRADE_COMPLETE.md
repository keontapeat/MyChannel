## 🎨 **DESIGN SYSTEM OVERVIEW**

### Color Philosophy (YouTube-Inspired)
```
PRIMARY:    YouTube Red (255, 0, 0)
BACKGROUND: Pure White / Almost Black
SURFACE:    Light Gray / Dark Gray
TEXT:       Almost Black / White

PRINCIPLE: 90% neutral, 10% color (professional!)
```

### Typography System
```
Display:  36-48px, bold    (Hero titles)
Headline: 24-32px, semibold (Section headers)
Title:    16px, medium      (Card titles)
Body:     14px, regular     (Descriptions)
Caption:  12px, regular     (Metadata)

FONT: System fonts (-apple-system, Segoe UI, Roboto)
```

### Spacing System
```
xs:  4px   (Tight grouping)
sm:  8px   (Related elements)
md:  16px  (Card padding)
lg:  24px  (Section spacing)
xl:  32px  (Major sections)
2xl: 48px  (Hero spacing)
```

### Animation Timing
```
Fast:   200ms (Hover effects)
Normal: 300ms (State changes)
Slow:   500ms (Page transitions)

EASING: ease-in-out (smooth, natural)
```
