## 🚀 **CONNECT CUSTOM DOMAIN (5 MINUTES)**

### Step 1: Open Firebase Console

Go to:
```
https://console.firebase.google.com/project/mychannel-ca26d/hosting/sites
```

### Step 2: Click "Add Custom Domain"

1. Click the "Add custom domain" button
2. Enter: `mychannel.live`
3. Click "Continue"

### Step 3: Verify Ownership

Firebase will show you a TXT record:
```
Type: TXT
Name: @
Value: (Firebase will provide this)
```

**Add this to your DNS provider** (where you bought mychannel.live):
- GoDaddy, Namecheap, Cloudflare, etc.

### Step 4: Add DNS Records

After verification, add these records:

**For Root Domain (mychannel.live)**:
```
Type: A
Name: @
Value: (Firebase will provide IP addresses)
```

**For WWW (www.mychannel.live)**:
```
Type: CNAME
Name: www
Value: mychannel-ca26d.web.app
```

### Step 5: Wait for Propagation

- DNS propagation: 15 minutes - 48 hours
- SSL certificate: Automatic (Firebase generates it)

### Step 6: Verify

After DNS propagates, test:
```
https://mychannel.live
https://www.mychannel.live
```

Both should show your website! ✅
