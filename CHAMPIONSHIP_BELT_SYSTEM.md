## 📊 RANKING SYSTEM

### **How Rankings Work**

```python
# After every match
if win:
    elo_gain = calculate_elo(your_elo, opponent_elo, result="win")
    ranking_points += elo_gain
    move_up_rankings()
else:
    elo_loss = calculate_elo(your_elo, opponent_elo, result="loss")
    ranking_points -= elo_loss
    move_down_rankings()
```

### **Ranking Formula**

```
Base Points: 1000
Win: +10 to +50 (based on opponent rank)
Loss: -5 to -30 (based on opponent rank)

Beat higher rank = more points
Beat lower rank = fewer points
Lose to lower rank = more point loss

Win Streak Bonuses:
- 3 wins: +5 bonus
- 5 wins: +10 bonus
- 10 wins: +25 bonus
- Undefeated: +50 per win after 10
```

### **Moving Up Divisions**

```
Bronze → Silver: 1500+ points
Silver → Gold: 2000+ points
Gold → Platinum: 2500+ points
Platinum → Diamond: 3000+ points
```
